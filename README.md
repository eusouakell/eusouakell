## Working thesis

The goal is not maximum context.

The goal is **minimum sufficient, authoritative context with measurable effect**.

```text
KNOWLEDGE AUTHORITY
        ↓
CONTEXT ROUTING
        ↓
SELECT · COMPRESS · ISOLATE
        ↓
TASK SKILL + TOOLS
        ↓
EXECUTION
        ↓
CHECKS · EVALS · HUMAN GATES
```

I am preparing a controlled benchmark using synthetic marketing examples to compare **prompt-only execution**, **full-context dumping**, **routed context** and **routed context with verification**. Model-quality results are not yet measured.
