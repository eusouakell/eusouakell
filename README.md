## Working thesis

The goal is not maximum context.

The goal is **minimum sufficient, authoritative context with measurable effect**.

![Marketing Context Stack](assets/marketing-context-stack.svg)

A useful context system needs to solve two different problems:

1. **Knowledge authority** — what is canonical, current, evidenced, superseded or derived.
2. **Runtime context** — what a model or agent should receive for this task, what should be excluded, and why.

I am testing this through controlled comparisons between prompt-only execution, full-context dumping, routed context and routed context plus verification. I do not publish performance claims before the experiment exists.

## Cereja as a public lab

Cereja Flamejante is where part of this work becomes concrete.

**Núcleo** governs meaning, evidence, voice and thesis state.

**Flame** governs visual language, interaction, motion and accessibility.

The **Editorial Engine** turns approved context into channel-native outputs while keeping publication human-approved.

This gives me a real environment to test context engineering, design-system traceability, accessible motion, agent skills and learn-back from human edits.
